# Unit Converter

A simple Android app that converts values between different units of measurement. Choose a category, pick the source and target units, enter a value, and tap **Convert** to see the result.


- Select a unit category (such as length, weight, or temperature)
- Choose a source unit and a target unit from dropdown menus
- Enter a value to convert
- Tap **Convert** to see the result instantly

## Tech Stack

- **Language:** Java
- **IDE:** Android Studio
- **UI:** XML layouts with `LinearLayout`, `Spinner`, `EditText`, and `Button`

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/unit-converter-app.git
   ```
2. Open the project folder in Android Studio.
3. Wait for Gradle to finish syncing.
4. Click **Run** (green triangle) and choose an emulator or a connected Android device.

## Download APK
